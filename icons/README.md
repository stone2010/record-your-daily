# PWA Icons

这个目录包含PWA应用图标。

## 图标要求

为了支持PWA功能，需要准备以下尺寸的图标：

- 72x72px
- 96x96px
- 128x128px
- 144x144px
- 152x152px
- 192x192px
- 384x384px
- 512x512px

## 生成图标

可以使用以下工具生成PWA图标：

1. [PWA Asset Generator](https://github.com/niklashohle/pwa-asset-generator)
2. [RealFaviconGenerator](https://realfavicongenerator.net/)
3. [Favicon.io](https://favicon.io/)

## 设计建议

- 使用简洁明了的图标设计
- 主色调建议使用应用的主题色（#ef7a1e）
- 确保图标在小尺寸下仍然清晰可辨
- 避免使用过多的文字或细节

## Apple Touch Icon

Apple设备需要一个额外的Apple Touch Icon：

- 文件名：apple-touch-icon.png
- 尺寸：180x180px
- 路径：/icons/apple-touch-icon.png
